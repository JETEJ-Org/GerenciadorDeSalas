# ROOM - Gerenciador de Salas

## Sobre o Projeto

O projeto **ROOM** é um sistema web que visa substituir o gerenciamento manual de salas, um processo pouco eficiente e suscetível a erros.

O objetivo é criar uma aplicação que automatiza o controle e a reserva dos espaços, permitindo um gerenciamento ágil, a visualização da disponibilidade das salas em tempo real e a otimização do uso da infraestrutura.

## Funcionalidades Planejadas

* **Gestão Centralizada:** Cadastro de usuários, salas e gerenciamento de permissões de acesso.
* **Sistema de Reservas:** Permite solicitar, modificar, cancelar e aprovar/negar reservas de salas.
* **Visualização de Status:** Exibe em tempo real se as salas estão disponíveis, ocupadas ou reservadas.
* **Sistema de Notas:** Usuários podem adicionar notas sobre as salas, como a necessidade de manutenção, que podem ser encaminhadas aos setores responsáveis.
